WEDDING INVITATION — VERSION 1

Files:
- index.html : complete invitation webpage, self-contained.
- music.mp3  : optional; add your chosen audio file with this exact name.

HOW TO CUSTOMIZE
1. Open index.html in a text editor.
2. Search for [YOUR NAME], [HER NAME], [VENUE], [TIME], and replace them.
3. Replace the photo placeholders in the gallery with your own images later.
4. Change the countdown time in the JavaScript target variable when the exact time is finalized.
5. Replace the map() function's alert with your real Google Maps URL.
6. Add music.mp3 in the same folder for background music.

NOTE
The guestbook currently stores messages in the browser's localStorage. For real guest submissions from different phones, connect the form to Google Sheets/Firebase/Supabase in the next version.
